# Scripts

Utility scripts for the PRPS project. Run from the repository root.

| Script | Purpose |
| --- | --- |
| `bootstrap-env.mjs` | Copies `.env.example` into `backend/.env` and `frontend/.env` when missing. Run via `npm run setup`. |

Additional automation (e.g., pre-commit checks, data export tooling) will be
added here in later phases.
